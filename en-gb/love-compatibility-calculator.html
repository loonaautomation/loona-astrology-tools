How It Works — The Method, Stated Openly

Each name's Destiny number is calculated with the Pythagorean chart (A, J, S = 1 through I, R = 9), keeping master numbers 11 and 22 as a flag but using the reduced 1–9 value for pairing. The pair score comes from a fixed table: the same number scores 90; specially harmonious pairs — (1,5) 88, (2,6) 92, (3,5) 90, (3,7) 84, (6,9) 89, (2,4) 82, (4,8) 85, (1,9) 83, (5,7) 86, (3,9) 87 — score as listed; neighbouring numbers score 78; all other pairs score 70 minus the difference between the numbers, with a minimum of 45. If both birth dates are entered, each Life Path number is calculated by reducing the month, day and year parts of the date and adding them, the same pair table scores them, and the final score is 60% name score + 40% Life Path score, rounded.

Frequently Asked Questions

How does this love compatibility calculator work?

It uses a fun name-numerology method, stated openly on this page. Each name is converted to a Destiny number with the Pythagorean letter chart and reduced to 1–9, then a fixed pair table scores how those two numbers combine. If you also enter both birth dates, each person's Life Path number is calculated and blended in — 60% name score and 40% Life Path score — for the final percentage.

Is this a real verdict on our relationship?

No — and this page says so plainly. The score is for fun and reflection only; it is entertainment, not a verdict. Real relationships are built through communication, kindness, trust and shared effort over time, none of which a calculator can measure. Treat a high or low score as a conversation starter, never as a decision-maker.

Why did adding birth dates change our score?

Because the method changes when both birth dates are present. Without dates, the score comes only from your two name (Destiny) numbers. With both dates, your two Life Path numbers are scored with the same pair table and blended in at 40%, so the final percentage can move up or down. Entering only one date changes nothing — both are needed for the blend.

What name should we each enter?

For consistency with numerology convention, enter each person's full birth name — first and last name as given at birth. Nicknames and shortened names give different letter totals and therefore different scores, which is fine for fun, but birth names keep results comparable with the other numerology tools on this site.
